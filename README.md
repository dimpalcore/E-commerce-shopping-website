# 🌸 GEN-Z STORE

### Your Style. Your Rules.

GEN-Z STORE is a modern and stylish e-commerce website designed for the Gen-Z generation. It provides a simple and attractive online shopping experience where users can explore different fashion products.

## 📌 About The Project

GEN-Z STORE is a frontend-based e-commerce website developed as a Software Engineering college project.

The website offers a user-friendly interface with a pink, white, and black theme. Users can browse products, search for their favourite items, filter products by category, and add products to their shopping cart.

## ✨ Features

- Attractive and responsive homepage
- Stylish pink and white user interface
- Product listing section
- Product categories:
  - Clothing
  - Shoes
  - Watches
  - Accessories
- Search products by name
- Filter products by category
- Add products to shopping cart
- Remove products from cart
- Automatic total price calculation
- Demo Login and Sign Up interface
- Contact and About sections

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Website styling and responsive design
- JavaScript – Website functionality

## 🚀 How To Run The Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select Open with Live Server.
5. Explore the GEN-Z STORE website.

## 🎯 Project Objective

The main objective of this project is to develop a simple and user-friendly e-commerce website using basic web development technologies and understand the fundamentals of frontend development.
